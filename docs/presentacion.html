Normativa Urbanística Galicia 3D Fase: desarrollo

Visor 3D con edificios OSM y análisis de normativa. Backend FastAPI, Frontend Three.js + MapLibre.

Visión y objetivos

  • Explorar en 3D el entorno urbano con edificios OSM y relieve.
  • Aplicar normativa (altura, retranqueos, ocupación, etc.) para generar volúmenes y validar casos.
  • Informes reproducibles con parámetros y geometrías, exportables a GLB y CityJSON.
  • IA (en evolución): extracción de reglas desde PDFs y preguntas/respuestas sobre normativa.

Tecnologías clave

Frontend

  • Three.js (modelos GLB/GLTF)
  • MapLibre GL JS (mapa y extrusiones)
  • Overpass API (OSM) con mirrors y rotación

Backend

  • FastAPI (Python)
  • Proveedor de planes CSV/mock
  • Endpoints /zoning/*, /proxy/*, /metrics

Operación

  • Scripts PowerShell de arranque/smoke
  • CI con smoke y pytest
  • Caché ligera por BBOX y refinado opcional

Flujo de uso

  1. Arrancar API y visor: scripts/run_viewer_demo.ps1 -Fast -Port 8010.
  2. Abrir http://127.0.0.1:8010/viewer/.
  3. Acercar a zoom ≥ 14.5 para ver edificios 3D. Botón: “Refrescar edificios”.
  4. Exportar GLB/CityJSON y generar informes desde la UI o script.

Estado actual

  • Exportaciones: GLB/GLTF (visor) y CityJSON (descarga) operativas.
