Ayuda

1. Carga subzonas con el boton superior.
2. Haz clic en una subzona para ver sus parametros.
3. Si la subzona tiene geometria, podras evaluar viabilidad.
4. O dibuja una parcela con el boton "Dibujar parcela".
5. La decision oficial viene del backend FastAPI.
